# CLAUDE.md — サンプル在庫管理システム（機能追加: CSV エクスポート + フィルター改修）

機能追加案件。既存の在庫管理システムに CSV エクスポートとフィルター改修を追加する。

## 変更スコープ

1. **CSV エクスポート**: 商品一覧画面にサーバーサイド生成の CSV エクスポートボタンを追加
2. **在庫フィルター改修**: 「10以下のみ」の固定フィルターを「任意の数値 + 演算子（以上/以下）」に変更

## 制約

- **既存のテーブル構成は変えない**（鈴木部長の指示）
- CSV エクスポートはサーバーサイド生成（Route Handler）
- フィルター UI は既存パターンを踏襲する

## 期限

2026-06-29（依頼日から2週間以内）
