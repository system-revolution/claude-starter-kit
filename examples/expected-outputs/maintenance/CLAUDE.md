# CLAUDE.md — サンプル在庫管理システム（保守対応: 商品検索バグ）

緊急バグ対応。商品名に `&` を含む商品を検索すると画面が真っ白になる問題。

## インシデント概要

| 項目 | 内容 |
|------|------|
| 種別 | バグ修正 |
| 緊急度 | 高 |
| 報告者 | 佐藤様（株式会社サンプル商事） |
| 発生日時 | 2026-07-10 14:00頃 |
| 影響商品 | 約10件（`&` を含む商品名） |

## 対応方針

1. `&` 文字を含む検索クエリの URL エンコード処理を修正
2. 他の検索機能（入出庫履歴・商品マスター等）で同種バグがないか確認
3. 修正後、入力バリデーション（特殊文字のサニタイズ）を追加

## 再発防止

- SKILL.md に「特殊文字を含む検索クエリのバリデーションルール」を追記
- 商品名に使用可能な文字種をユーザーに明示する（UI にヒントを追加）
