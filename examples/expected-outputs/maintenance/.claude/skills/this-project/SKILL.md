## 学習: 2026-07-10 特殊文字を含む検索クエリ

- 問題: 商品名の `&` 文字が URL エンコードされずに検索クエリに渡り、画面が真っ白になった
- 対策: 検索入力値は必ず `encodeURIComponent()` を通してから URL パラメータに渡す。サーバー側でも `decodeURIComponent()` で受け取る

## 検索機能の実装ルール（再発防止）

- 検索クエリを URL パラメータに渡す際は必ず `encodeURIComponent()` を使う
- Next.js の `useSearchParams` / `router.push` を使う場合も手動エンコードが必要（Next.js は自動エンコードしない場合がある）
- 商品名・備考など自由入力フィールドを検索に使う箇所は全てこのルールを適用する
