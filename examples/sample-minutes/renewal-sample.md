# リニューアル案件サンプル議事録

架空の案件: **既存WordPressサイトを Next.js + Supabase へリニューアル**

---

## 打ち合わせ議事録

日時: 2026-04-10 14:00〜15:00
参加者: 田中(弊社)、高橋(株式会社リニューアル例)

## 既存システム

- WordPress + MySQL
- 10年運用、テーマはカスタマイズされている
- 月間PV:50,000
- 投稿数:約2,000記事
- 問い合わせフォームはContact Form 7

## 現状の問題

- WordPress の更新で毎回トラブル発生
- 表示速度が遅い(PageSpeed Insights: 30点)
- スマホ対応が不十分
- 管理画面が使いにくい
- セキュリティ対応(プラグイン脆弱性)に毎月工数がかかる

## リニューアル方針

- 新スタック:Next.js + Supabase + Vercel
- 既存コードは引き継がない(ゼロから作り直し)
- 既存データ(記事・画像)は移行する
- ドメインは同じ

## 残すもの

- 記事データ(2,000件)
- 画像(約5GB)
- ドメイン
- URL構造(SEO維持のため同じパス)

## 変えるもの

- デザイン全面リニューアル
- スマホファースト
- 表示速度の大幅改善
- 管理画面を使いやすく

## 追加するもの

- 検索機能の強化(全文検索)
- 関連記事の自動表示
- SNSシェア連携

## スケジュール

- 開発期間:4ヶ月
- リリース:2026年8月予定

## 予算

- 初期費用 200万円
- 月額 Vercel Pro + Supabase Pro で1万円程度を想定
