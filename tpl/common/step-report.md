# 共通: 最終報告

全作業完了後に報告する定型。

## 報告フォーマット

```
## 作業完了報告

### 1. 変更ファイル一覧
[箇条書きで変更・追加・削除したファイル]

### 2. 変更内容の要約
[2〜3行で何をしたか]

### 3. テスト結果
- lint: ✅ / ❌
- typecheck: ✅ / ❌
- unit test: ✅ / ❌ (カバレッジ XX%)
- E2E test: ✅ / ❌

### 4. セキュリティチェック結果
- differential-review: 0件 / N件(内訳...)

### 5. 更新したドキュメント
- docs/database.md: ✅ 更新 / 更新不要
- docs/api-endpoints.md: ✅ 更新 / 更新不要
- docs/features.md: ✅ 更新 / 更新不要
- CLAUDE.md: ✅ 更新 / 更新不要

### 6. 既存機能への影響
[影響あり/なし、ありの場合は詳細]

### 7. 残課題・引き継ぎ事項
[次回以降に対応が必要な事項]

### 8. 学習ログ追記
[self-improve スキルで追記した内容、なければ「なし」]

---
テストが全て通過しセキュリティチェックが完了しました。
確認をお願いします。マージ指示をお待ちしています。
```

## 禁止事項

- 報告フォーマットの省略
- テスト未実行での報告
- セキュリティチェック未実施での報告
- 「多分大丈夫」のような曖昧な記述
- ユーザー確認前のmainマージ
