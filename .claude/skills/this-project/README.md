# .claude/skills/this-project/

このディレクトリにはプロジェクト固有のスキルを配置する。

## SKILL.md の役割

`SKILL.md` は作業開始時・判断が必要な時に読み込まれる詳細版ルールファイル。

CLAUDE.md には常時読む必要がある最小限の情報だけ書き、詳細はすべてここに書く。

```
CLAUDE.md（常時読み込み）
  ↓ 参照する
SKILL.md（作業開始時・判断時のみ読み込み）
  - プロジェクトの業務ルール
  - 禁止事項
  - 外部 API 仕様
  - 作業プロトコル
```

## 生成タイミング

テンプレート処理の Step 3（設計ドキュメント生成）で Claude Code が生成する。

## ベースリポジトリの管理範囲

- このディレクトリの `.gitkeep` のみベースリポジトリで管理する
- `SKILL.md` は各プロジェクトが生成・管理する
- ベース更新時にこのディレクトリの内容は上書きしない
